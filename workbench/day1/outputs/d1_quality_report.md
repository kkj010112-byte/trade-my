## 4. 처리 순서 제안 (2일차용, 아직 실행하지 않음)

1. 중복 3행 정리 (2-1절) — 이후 모든 집계의 전제.
2. 통화 표기 8종 → 4개 코드 통일. `¥` 2건 확인.
3. 금액 · 연체일 글자 셀 20개: 기계 변환 12건 → 변환, 어림값 6 · 값 아님 2 → 결측 + 확인 목록.
4. since_date 형식별 파싱, 모호 15건 확인 목록.
5. payment_terms_raw → `payment_terms_map`으로 표준 코드 + 기간(일).
6. country는 country_code로 다시 붙임.
7. 결측의 뜻을 플래그로 분리: pay_score(완납 3건 미만) · oecd_crc `-`(분류 대상 아님) · 재무(미수령/미공개) · D/E 음수(자본잠식).

원본 `data/day1/d1_buyers_raw.xlsx`는 그대로 두고, 고친 결과는 `workbench/day2/data/` 사본으로 만듭니다.
